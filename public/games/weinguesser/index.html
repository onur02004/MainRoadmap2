Street View açılmıyor mu?

Bu sürüm doğrudan Maps Embed API iframe’ini kullanır. Maps JavaScript API etkinleştirmen veya yeni API türü eklemen gerekmez. Önceden çalışan Embed API anahtarını kullanabilirsin.

  1. Google Cloud’da API anahtarının bağlı olduğu projeyi seç.
  2. Maps Embed API hizmetinin etkin olduğundan emin ol.
  3. Anahtarın API kısıtlamalarında Maps Embed API’ye izin ver.
  4. Web sitesi kısıtlamalarına http://localhost:3170/* ve http://127.0.0.1:3170/* adreslerini ekle.
  5. Projede faturalandırmanın etkin olduğunu kontrol et.
